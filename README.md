## AI Agentic Engineering — Building Autonomous AI Agents

### A hands-on journey to code and deploy AI Agents with OpenAI Agents SDK, CrewAI, LangGraph, Google ADK, Pydantic AI and MCP

![Autonomous Agent](assets/agentic.jpg)

Welcome! This repository is a practical, project-based introduction to the powerful and often surreal world of Agentic AI — building autonomous agents that can plan, use tools, and work together to complete real tasks.

### What's inside

This repository walks through building AI Agents using several of the leading frameworks and protocols in the space:

- OpenAI Agents SDK
- CrewAI
- LangGraph
- Google ADK (Agent Development Kit)
- Pydantic AI
- MCP (Model Context Protocol)

Each framework is covered with working code examples so you can compare approaches and pick the right tool for a given project.

### API costs — please read

Working through this material involves making calls to OpenAI and other frontier models, which requires an API key and a small amount of spend (set up as part of the setup instructions above). If you'd prefer not to spend on API calls, there are cheaper alternatives such as DeepSeek, and free alternatives such as running models locally with Ollama.

Details on these alternatives are covered in [this guide](guides/09_ai_apis_and_ollama.ipynb).

Be sure to monitor your API usage and costs to make sure you're comfortable with any spend. For OpenAI, the usage dashboard is [here](https://platform.openai.com/usage).
